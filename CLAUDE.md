For relay/protocol documentation, code is the source of truth: verify Kotlin `RelayKindDescriptors`, Rust relay-core `RelayKind` / `RelayBackend` / transport descriptors, crate existence under `native/rust/crates/`, schema version `8`, and tests before writing claims. Snowflake is still the external Go PT binary per `docs/architecture/snowflake-native-rust-decision.md`; VLESS Reality does not use real ECH per `docs/adr/0001-reality-ech.md`.

The `PreToolUse` hook blocks edits to `*baseline*` files -- the baseline policy in AGENTS.md § Project Rules is hook-enforced for Claude Code.

Worktree & commit workflow: perform every job or feature -- especially dynamic `workflow` / `/goal` runs -- in a dedicated git worktree (`claude --worktree <slug>` or the `EnterWorktree` tool; subagent and Workflow fan-out that writes uses `isolation: worktree`, read-only fan-out needs none), never directly on the `main` checkout. Each atomic unit of work is its own Conventional Commit. Decompose by crate/module boundary and keep high-risk shared files (`Cargo.lock`, `gradle/libs.versions.toml`, `*.proto`/wire schema, the 7 locale `strings.xml`, `*baseline*`, goldens) in a single serialized lane. Rebasing the worktree branch onto `main` and deleting the work branch/worktree is NEVER automatic -- STOP and get the user's explicit confirmation first; before the fast-forward merge, rebase onto latest `origin/main` and re-run the gates on the *combined* tree. Never `git rebase`/`git merge` onto `main`, `git worktree remove`, `git branch -d`, or `git push` without that confirmation. See AGENTS.md § Git Worktree & Commit Workflow for the canonical sequence, the high-risk-file ledger, and `docs/contributor/build-performance.md` § Parallel agent builds for cache/daemon isolation.

Long-form cross-tool rules live in `.claude/rules/` and apply to both Claude Code and Codex. See AGENTS.md § Project Rules for the routing table.

The app ships 7 locales (en, ru, es, de, fr, fa, zh-CN). Any new key added to `app/src/main/res/values/strings.xml` or `core/service/src/main/res/values/strings.xml` must land in all six matching `values-XX/strings.xml` files in the same commit. `lint.xml` has `MissingTranslation severity="error"` -- a missing key fails CI. `scripts/check-readme-selectors.sh` enforces selector-block parity across all 7 README files. See AGENTS.md § Project Rules for the full rule and verification commands.
