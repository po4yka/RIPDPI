RIPDPI · Mobile adoption

VPN connection state, on a phone.

Six connection-state preview elements adopted into the Android UI kit. Each section is composed from existing kit primitives — RipDpiCard, MetricPill, SectionHeader, RipDpiButton, WarningBanner — with view-specific bits drawn from the same token contract.

  1. Lifecycle — linear state flow with current ring; desktop 2D graph re-expressed as a vertical column
  2. Handshake timeline — 9 phases stacked, label above bar, NOW marker aligned to bar column
  3. Session card — uptime, exit, sparklines, KPI strip, footer actions
  4. Reconnect toasts — in-progress (with countdown), failed-after-N, recovered
  5. Degradation strip — warn + critical variants, reason chips, action pair
  6. State history — stacked summary + 24-cell ribbon + recent transitions log

Source: ui_kits/android/MobileVpnConnection.jsx. Web previews at preview/vpn-*.html.
