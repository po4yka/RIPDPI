RipDpiTextAction — the low-emphasis, text-only action. No container, no border, no button padding: RipDpiButton owns everything that needs chrome, this owns the cases that read as a link (Skip, Finish anyway, inline dismissals). Colour and type scale come from the caller, because a text action inherits the tone of the surface it sits on rather than carrying a variant palette; the default is type.button at muted-foreground. Routed through ripDpiClickable, so haptics, focus and the minimum interactive size match every other control. Disabled falls to muted-foreground.
