RIPDPI · Mobile adoption

Element library, on a phone.

Mobile recomposition of the new RDS primitives — each composed naturally inside a real app screen, not isolated on a spec card.

  1. Live state — heartbeat, live counter, stale badge, progress bar, shimmer
  2. Search & filter — command palette, kbd, filter bar, combobox
  3. Inputs — slider, segmented, tabs, CIDR input, stepper
  4. Data surfaces — log stream, JSON tree, unified diff, accordion
  5. Onboarding — coach mark overlay, what's-new sheet

Motion specs (easing curves, probe pulse, toast choreography…) and a11y specs (focus rings, contrast pairs) are universal — they apply across every mobile surface and are already manifest in existing mobile screens.

Gestures (pull-to-refresh, swipe-actions, long-press) are mobile-native by definition — see the previews under Design System → Gestures.
