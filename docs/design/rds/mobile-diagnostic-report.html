RIPDPI · Mobile adoption

Diagnostic report, on a phone.

The six diagnostic-report preview elements adopted into the Android UI kit. Every section is composed out of existing kit components — RipDpiCard, MetricPill, SectionHeader, RipDpiChip, RipDpiButton, WarningBanner — with view-specific bits drawn from the same token contract.

  1. Report summary — 2-column KPI grid, stage strip, two-button footer
  2. Hop trace — vertical rail, ASN under each IP, right-aligned RTT + bar
  3. Path-MTU scan — compact scale, ladder shrunk to 5 most informative rows
  4. Port matrix — per-target chunks of 6-wide tile grids (no 12-col table on mobile)
  5. Interference signatures — one card per signature, confidence meter inline
  6. DNS resolvers — per-resolver card, success bar + tip banner

Source: ui_kits/android/MobileDiagnosticReport.jsx. Web previews remain at preview/diagnostic-*.html.
