## Dependency rationale

`yaml_serde 0.10.7` and `libyaml-rs 0.3.0` replace the archived parser packages. The [YAML project](https://yaml.com/projects/yaml-serde/) and [libyaml-rs repository](https://github.com/yaml/libyaml-rs) identify YAML Organization maintenance. Published archive checksums match Cargo.lock. Licenses are MIT/Apache-2.0 and MIT; their MSRV values of 1.82 and 1.60 fit the pinned 1.98.1 toolchain. Neither adds a build script or proc macro. No new transitive package is added.

This fixes the unmaintained-package advisory, not a newly confirmed memory-safety vulnerability. The parser core still contains unsafe Rust translated from C. Tests preserve strict typed scalars, aliases, enum tags, duplicate rejection, existing unknown-field rules, validation errors and syntax-error privacy.

The targeted Cargo update also reselects three existing flexible edges: generator uses windows-link 0.2.1, pwd-grp uses thiserror 2.0.21 and tempfile uses getrandom 0.4.3. Their manifests permit these versions, which already existed in the graph. No other package version or checksum changes. The lockfile is generated by Cargo, not edited by hand.
