## Verification

The scheduler writes a fixed warning to the Android diagnostics log when a
background check throws. The warning contains no exception or network details.
The regression test failed before the fix because the warning was absent.
After the fix it verified the warning, the empty history after failure, and a
successful later check. All 453 detection tests, Ktlint, Detekt, and
`just ci-gates` passed.
