# RIPDPI — Инструкция по диагностике

Как проверить сеть и отправить отчет.

# Что вам понадобится

- Android-телефон с версией Android 8.1 или выше
- Установленное приложение RIPDPI
- Подключение к интернету (Wi-Fi или мобильные данные)

При первом запуске приложение запросит разрешение на создание VPN-соединения — нажмите **Continue** и подтвердите.

# Запуск диагностики

> **Важно:** Для RAW_PATH-сканирования приложение само приостанавливает активный VPN/прокси, запускает проверку напрямую и после завершения восстанавливает прежнее состояние. Отключать соединение вручную не требуется.

1. Откройте приложение RIPDPI.
2. Перейдите на экран **Диагностика** через раздел **Тесты**.
3. Выберите вкладку **Сканирование**.
4. Прокрутите список профилей до группы **Россия Сеть**.
5. Выберите профиль полной проверки сети.
6. Нажмите **Запустить сканирование напрямую**.
7. Дождитесь завершения — это займет 2–5 минут.

Во время сканирования вы увидите результаты зондов в реальном времени:

- **Зеленый** — всё в порядке, помех нет
- **Желтый** — частичная проблема
- **Красный** — заблокировано или подменено

Не закрывайте приложение до завершения сканирования.

# Отправка результатов

После завершения сканирования:

1. Перейдите на вкладку **Инструменты** на экране **Диагностика**.
2. Нажмите **Поделиться архивом**.
3. В открывшемся меню выберите способ отправки (Telegram, почта, или другой мессенджер).
4. Отправьте архив мне.

> **Что содержит архив:** Архив включает результаты зондов, сведения о среде сети и версию приложения. Сводка и manifest проходят редактирование чувствительных полей, но исходные диагностические отчеты и явно включенный PCAP могут сохранять необработанные сетевые данные. Делитесь архивом только осознанно и только с доверенным получателем.

# Если нужна дополнительная проверка

Если я попрошу запустить пробу стратегий обхода:

1. Откройте **Диагностика** > вкладка **Сканирование**.
2. Прокрутите список до группы **Автозондирование**.
3. Выберите профиль **Автоматическое зондирование**.
4. Нажмите **Запустить автоматическое зондирование**.
5. Дождитесь завершения (1–2 минуты).
6. Перейдите на вкладку **Инструменты** > **Поделиться архивом** и отправьте архив мне.

> **Во время автоматического зондирования:** строка состояния может показывать текущую дорожку **TCP** или **QUIC** и номер кандидата, например `TCP 3/14`. Это нормально: приложение по очереди проверяет разные варианты.

Для более полной проверки я могу попросить запустить **Автоматический аудит** (группа **Автоаудит**) — это займет 5–10 минут. Каждый запуск проверяет одну отобранную группу целей, а в отчете сначала показывает лучший путь с вариантами TCP и QUIC, оценку уверенности/охвата и кнопку раскрытия полной матрицы.

> **Если автоматическое зондирование или аудит недоступны:** отключите **Use command line settings** в расширенных настройках и вернитесь на вкладку **Сканирование**. Автоматические прогоны работают только с визуальными настройками RIPDPI, потому что приложение запускает временные изолированные испытания стратегий.

# Если приложение упало

Если приложение вылетело (краш), после перезапуска:

1. Откройте **Диагностика** > вкладка **Инструменты**.
2. Нажмите **Сохранить логи** — сохраните файл.
3. Отправьте сохраненный файл `ripdpi.log` мне.

# Если что-то пошло не так

| Проблема | Что делать |
|----------|-----------|
| Сканирование зависло | Отмените (кнопка отмены) и запустите заново |
| Приложение просит VPN-разрешение | Подтвердите разрешение |
| Все результаты красные | Это нормально — именно это мы и хотим увидеть. Отправьте отчет |
| Нет интернета | Проверьте подключение, попробуйте переключиться между Wi-Fi и мобильными данными |
| Автоматическое зондирование / аудит недоступны | В расширенных настройках отключите Use command line settings и вернитесь на вкладку Сканирование |
| Не вижу нужный профиль | Прокрутите список профилей вниз — они сгруппированы по категориям |
