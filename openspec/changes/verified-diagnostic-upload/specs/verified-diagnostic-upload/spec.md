## ADDED Requirements

### Requirement: REQ-DGN-1795322193627833-001 — Admit a bounded manual HTTPS upload

A user-initiated scan SHALL accept one HTTPS endpoint and a size of 1 to 1,048,576 bytes. It SHALL send one POST of locally generated bytes on the selected path.

#### Scenario: The user enters a valid control endpoint

- **WHEN** the URL and size are valid and the user starts the scan
- **THEN** the scan sends the selected number of generated bytes once

### Requirement: REQ-DGN-1795322193627833-002 — Verify the full server receipt

The scan SHALL require HTTP 200 and a complete JSON receipt of at most 512 bytes. The receipt SHALL contain the received byte count and SHA-256 of the received body. A successful result requires both values to match the local upload. The result SHALL omit the body, endpoint URL, and digest.

#### Scenario: The server returns a partial or incorrect receipt

- **WHEN** the receipt stalls, ends early, or reports an incorrect size or digest
- **THEN** the scan reports the corresponding failure outcome
