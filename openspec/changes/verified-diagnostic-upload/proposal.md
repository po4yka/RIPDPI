# Verify a bounded manual HTTPS upload

Task ID: `DGN-1795322193627833`

## Why

An HTTPS connection and a successful write do not show that the server read the request. A control server receipt can confirm the complete upload.

## What Changes

- Add a manual diagnostics profile that sends one bounded body of generated bytes over HTTPS.
- Verify the byte count and SHA-256 from the server receipt. Report transport and receipt failures.

## Capabilities

### New Capabilities

- `verified-diagnostic-upload` — One bounded HTTPS upload with server receipt verification.

### Modified Capabilities

- None.

## Impact

Android diagnostics, the native transfer runner, and the optional diagnostics request and results.
