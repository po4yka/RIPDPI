## Purpose

Define the observable completion contract for Add an own-server entry point to onboarding and home. A new user who has their own VPN server finds how to add it during onboarding and from the home and Connection screens.

## ADDED Requirements

### Requirement: REQ-UIX-1795615850526190-001 — Onboarding has an optional, skippable step that offers Paste link, Scan QR, Imp…

The RIPDPI implementation MUST satisfy this portfolio criterion: Onboarding has an optional, skippable step that offers Paste link, Scan QR, Import file, and Add manually.

#### Scenario: Verify criterion 1

- **WHEN** the linked change is exercised under the conditions defined by the portfolio task
- **THEN** the observed result MUST demonstrate that onboarding has an optional, skippable step that offers Paste link, Scan QR, Import file, and Add manually
