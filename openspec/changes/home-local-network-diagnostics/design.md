# Design

Read the captive portal and Internet validation flags from the physical network fingerprint. This capture already supplies the physical identity used by the Home run scope. Keep both flags unknown when capture is unavailable.

Show one local network notice above the analysis findings. A confirmed captive portal takes priority and gives the sign-in and repeat steps. An unvalidated network without a portal gets an explanation of the Android observation. The Home scope checks discard measurements after a network change. Check the scope again after saving the report and before publishing the local network notice. Capture the current fingerprint when delivering a completed result and refresh it on physical handover. Display the notice only when the result matches the current fingerprint. The notice uses passive platform state.
