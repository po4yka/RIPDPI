## Purpose

Provide accurate Arabic copy and locale-aware Home evidence without changing raw diagnostics or user data.

## ADDED Requirements

### Requirement: REQ-AR-COPY — Correct audited resource meaning

The app MUST correct all 86 confirmed resource entries and retain sensitive-setting warnings, recovery actions and protocol identifiers.

#### Scenario: Arabic warning and configuration

- **WHEN** Arabic is selected and audited controls are shown
- **THEN** warnings and descriptions convey the English meaning, including network ports, suffixes, cache misses and cloud sync

### Requirement: REQ-AR-HOME — Localize generated Home presentation

The app MUST localize the eight confirmed groups of generated Home text through app resources while retaining priority, limits, uncertainty and evidence.

#### Scenario: Completed or invalidated analysis

- **WHEN** Arabic is selected and Home displays network, routing, DNS, capability, bufferbloat, synthesized or invalidated-scope results
- **THEN** known generated captions and wrappers use Arabic and raw technical values stay exact

### Requirement: REQ-AR-RETAINED — Refresh presentation without raw mutation

The app MUST rebuild generated presentation when the app language changes and MUST preserve raw records, exports and unrecognized custom text.

#### Scenario: Retained analysis changes language

- **WHEN** the same retained result is shown in English, Arabic and English without a source emission
- **THEN** its generated presentation changes each time and raw evidence stays unchanged

#### Scenario: Custom evidence

- **WHEN** a custom label, host, URL, package identifier or unknown prose reaches presentation
- **THEN** the app preserves the value and does not apply broad text replacement

### Requirement: REQ-AR-PARITY — Preserve locale and visual contracts

The app MUST provide each new key in all ten locales with correct placeholders and plural categories. Confirmed RTL layout defects MUST have an observed reproduction before a source fix.

#### Scenario: Combined validation

- **WHEN** resource, behavior, lint and screenshot gates run on the combined source
- **THEN** they pass without changed quality baselines or unapproved golden updates
