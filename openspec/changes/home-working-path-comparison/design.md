# Design

Use completed RAW reports. Keep the catalog target from its source profile, including the HTTP path, ports and address requirements. Reserve one slot within the three domain target slots for a non-control domain with a complete successful HTTP response. Keep up to two foreign controls with a successful HTTP response. A working domain can supply its own direct baseline.

Use the HTTP outcome for paired HTTP evidence even when the separate TLS probe succeeds. Keep local response size and encoding limits distinct from path failure. Partial reports cannot seed the comparison or establish a regression.
